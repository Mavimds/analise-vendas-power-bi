# Imagens do Dashboard

Esta pasta reúne as capturas de tela das páginas desenvolvidas no projeto de análise de vendas utilizando Power BI.

As imagens apresentam as principais visualizações, indicadores e análises construídas, permitindo conhecer a estrutura e os resultados do dashboard sem a necessidade de abrir o arquivo `.pbix`.

## Conteúdo

- `visao-geral.png`: apresenta os principais indicadores de desempenho comercial, incluindo receita realizada, receita estimada e análises por produto, canal de venda e estado.
- `analise-produtos.png`: apresenta a análise de desempenho dos produtos, considerando receita, lucro, margem de lucro e quantidade vendida.
